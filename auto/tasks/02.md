# 02 — Build the Java CUDA runtime demo

## Goal
Create the smallest presenter-safe example proving that Java code can directly reach the CUDA runtime through the current TornadoVM Hybrid API, without handwritten JNI.

## Acceptance

- Runnable demo source is committed.
- Clean-machine setup/run commands are documented.
- Actual runtime/API calls and output are captured.
- Demo includes a deterministic validation check.
