# 03 — Build the cuBLAS Hybrid API demo

## Goal
Create a minimal Java demo that combines TornadoVM CUDA execution with a current cuBLAS provider through the Hybrid API.

## Required evidence

- exact TornadoVM SHA;
- exact cuBLAS/provider API used;
- canonical `java @arg-file ...` invocation when an arg-file is available;
- JBang invocation when practical, or a documented reason it is not suitable;
- correctness validation against a Java/reference implementation;
- captured stdout/stderr and any profiler evidence that materially explains the demo.

## Acceptance

A presenter can run the demo from the documented commands and observe a deterministic validated result.
