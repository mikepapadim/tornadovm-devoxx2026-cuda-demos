# 04 — Build the cuFFT Hybrid API demo

## Goal
Create a small Java FFT demo using TornadoVM CUDA plus the current cuFFT provider through the Hybrid API.

## Required evidence

- exact TornadoVM SHA and CUDA environment;
- current cuFFT API/provider verified from source and runtime;
- `java @arg-file ...` invocation when an arg-file exists;
- JBang invocation when practical, otherwise explicit explanation;
- numerical validation against a Java/reference implementation;
- captured run output and relevant profile evidence.

## Acceptance

The demo is runnable, validated, and documented as presenter-ready or clearly blocked with captured evidence.
