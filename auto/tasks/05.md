# 05 — Build the combined Java kernel + NVIDIA library demo

## Goal
Create the flagship Hybrid API live-coding example: a Java-written GPU kernel followed by a vendor-library operation in the same application/dataflow.

Prefer a cuBLAS or cuFFT composition that makes device-buffer reuse and the absence of handwritten JNI visually obvious.

## Run conventions

- Show the canonical `java @arg-file ...` command when the checked-out tree provides a suitable arg-file.
- Include a tested JBang invocation or explain why the demo needs a fuller TornadoVM environment.

## Acceptance

- One end-to-end demo is runnable and validated.
- The narrative identifies exactly which work is Java, which call is NVIDIA-provided, and how data moves between them.
- Failure/recovery steps are captured for a live conference setting.
