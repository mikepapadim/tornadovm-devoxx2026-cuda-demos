# 07 — Reproduce current GPULlama3.java on TornadoVM CUDA

## Goal
Establish a reproducible baseline for the LLM talk using the current GPULlama3.java/TornadoVM CUDA integration, not stale README claims.

## Steps

- Pin the GPULlama3.java revision and TornadoVM revision used.
- Follow the current build instructions, correcting them only with source-backed evidence.
- Run one small Llama model locally on the TornadoVM CUDA backend.
- Capture tokens/s, model, prompt, context, memory settings, JDK, GPU, and run id.
- Inspect current quantization support and test Q4/Q8/FP16 paths where code and model availability permit.
- Record failures and unsupported paths precisely.

## Acceptance

At least one current LLM inference path is reproduced on the CUDA backend, with raw output and environment evidence; all other paths are classified honestly.
