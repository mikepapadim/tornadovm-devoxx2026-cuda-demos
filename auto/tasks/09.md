# 09 — Generate evidence-backed drafts for both Devoxx talks

## Goal
Turn the verified study outputs into draft talk content without inventing capabilities or performance numbers.

## Deliverables

- `docs/talk-1-hybrid-api.md`
- `docs/talk-2-llm-inference.md`
- `docs/demo-runbook.md`
- `docs/claims.md`

Each talk draft should contain:

1. audience problem and opening story;
2. architecture/model explanation;
3. live-coding sequence with exact commands;
4. expected outputs/screens to point at;
5. one or two quantitative evidence moments;
6. likely failure modes and recovery path;
7. conclusion and Java/NVIDIA/JVM takeaways;
8. a list of claims that remain blocked or require verbal caveats.

Use the exact `java @arg-file ...` commands discovered during the study. Include JBang commands for demos where JBang was actually validated.

## Acceptance

Both drafts are internally coherent, every factual claim has an evidence classification, and every live demo has a tested canonical command or explicit blocker.
