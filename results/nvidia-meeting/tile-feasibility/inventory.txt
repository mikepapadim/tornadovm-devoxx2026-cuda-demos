=== RE-VERIFICATION (2026-09-04), after a false-zero risk was found ===

The original probe used `find` without -L. `find` defaults to -P and does not
follow symlinks, and /usr/local/cuda/include is a link to
targets/x86_64-linux/include -- so on a host that HAS tile files the command
could report zero. Re-run here with -L, and with the *volatile* false positives
filtered (the glob *tile* matches is_volatile.h / remove_volatile.h /
add_volatile.h in every CUDA release):

  find -L /usr/local/cuda*/ -iname '*tile*' | grep -iv volatile   -> 0
  ls  $CUDA_INC/crt/cuda_tile.h                                   -> absent
  grep -oE "__tile[a-z_]*__" $CUDA_INC/crt/host_defines.h         -> 0
  nm -D libnvrtc.so.12 | grep -ci tile                            -> 0

The CUDA 12.6.85 result is GENUINE, not an artifact of the weaker command.
